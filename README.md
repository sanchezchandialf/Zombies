# ERA Z — 1800 · 2100

Supervivencia por oleadas contra zombis a través de tres siglos. Juego original en **Three.js**, en español.

- Cada oleada es un día; cada día el calendario avanza 10 años. Seis eras, de la pólvora al plasma.
- Cinco roles con virtudes y defectos; ocho clases de zombi que los contrarrestan o caen ante ellos.
- Armas, equipo, vehículos y escenarios adaptados a cada época.

## Desarrollo

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # genera dist/
```
